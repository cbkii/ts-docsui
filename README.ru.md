# Файловый менеджер для TS18

[English](README.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

`ts-docsui` — модуль Magisk для поддерживаемых магнитол Topway TS18 с Android 10. Он восстанавливает системное окно выбора файлов, сохраняет штатный Android-провайдер обычной памяти и добавляет отдельный источник с Magisk root.

## Возможности

- Обычная внутренняя память `/storage/emulated/0` через штатный Android ExternalStorageProvider.
- Дополнительный пункт **Internal storage (full)**.
- Пункт **Root file system** для путей, доступных только с root.
- USB-накопители TS18, когда совместимый накопитель подключён и смонтирован.
- Выбор файлов и папок в приложениях, использующих Android SAF.

> [!TIP]
> При первом открытии папка на TS18 иногда ошибочно выглядит пустой. Сначала обновите текущую папку и только затем считайте это отказом провайдера.

## Требования

- Topway TS18 / UIS8581A / SP9863A;
- Android 10 / API 29;
- уже работающий Magisk 28 или новее.

Не считайте TS10, TS10S и внешне похожие устройства взаимозаменяемыми. Этот модуль не устанавливает Magisk и не получает root самостоятельно.

## Два варианта выпуска

Каждый выпуск содержит два устанавливаемых ZIP с одинаковой рабочей реализацией:

- `ts-docsui-v<versionCode>.zip` — компактный финальный модуль только с необходимыми рабочими компонентами.
- `ts-docsui-debug-v<versionCode>.zip` — отладочный модуль с ограниченным сборщиком диагностики и кнопкой **Action** в Magisk.

Для обычной работы используйте финальный ZIP. Отладочный ZIP устанавливайте только для сбора доказательств. Оба варианта имеют ID `ts-docsui`, поэтому установка одного заменяет другой; одновременно устанавливать их нельзя.

## Установка

1. Скачайте один ZIP из [последнего выпуска](https://github.com/cbkii/ts-docsui/releases/latest).
2. В Magisk откройте **Модули** и выберите **Установить из хранилища**.
3. Выберите ZIP.
4. Перезагрузите магнитолу.

После перезагрузки обычная внутренняя память должна оставаться штатным источником Android. Полная внутренняя память и корневая файловая система предоставляются отдельным root-провайдером. USB-пункты появляются только при смонтированном накопителе.

## Диагностика

Диагностика есть только в отладочном варианте. Нажмите **Action** в Magisk или выполните:

```sh
su -c '/data/adb/modules/ts-docsui/tools/ts18-saf-deepdiag.sh full'
```

Все рабочие файлы диагностики, журналы и проверенные архивы сохраняются в:

```text
/storage/emulated/0/Download/ts-docsui/diagnostics/
```

Обычные журналы установки и службы сохраняются в:

```text
/storage/emulated/0/Download/ts-docsui/logs/
```

`/data/adb/ts-docsui` используется только для небольшого обязательного состояния, root helper и маркеров согласования.

## Безопасность

Модуль работает systemless через Magisk и не прошивает boot, MCU, CAN, LCD, логотип или разделы прошивки.

Источник **Root file system** имеет настоящий root-доступ, но root не делает разделы device-mapper для чтения доступными для записи. Не изменяйте защищённые пути system, vendor, metadata, Magisk или состояния Android.

Прошивка с root, используемая проектом, взята из [темы сообщества Topway TS10 и TS18 на 4PDA](https://4pda.to/forum/index.php?showtopic=1015856). Она находится вне этого репозитория и не доказывает совместимость другого устройства.
