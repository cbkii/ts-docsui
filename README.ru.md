# TS18 Full File Picker

[English](README.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

Это модуль Magisk для исправления системного окна выбора файлов на поддерживаемых автомобильных магнитолах TS18.

## Для чего нужен этот модуль

На некоторых устройствах TS18 окно выбора файлов показывает только папку **Download** и USB-накопители. Приложения не могут выбрать файлы или папки из других мест внутренней памяти.

Модуль восстанавливает обычное окно выбора файлов Android 10 и добавляет отдельный источник файлов с root-доступом.

## Что добавляет модуль

- Доступ ко всей обычной внутренней памяти в `/storage/emulated/0`.
- Дополнительный пункт **Internal storage (full)** — полная внутренняя память.
- Пункт **Root file system** для файлов, которым нужен root-доступ через Magisk.
- USB-накопители TS18, когда они подключены.
- Выбор файлов и папок в приложениях, которые используют системное окно Android.

## Требования

- Магнитола Topway **TS18** с Android 10.
- Аппаратная платформа TS18 UIS8581A / SP9863A.
- Уже работающий Magisk 28 или новее.

Модуль не предназначен для TS10, TS10S и других похожих устройств.

## Источник прошивки с root

Прошивка TS18 с Magisk root, используемая с этим проектом, взята из [темы сообщества Topway TS10 и TS18 на 4PDA](https://4pda.to/forum/index.php?showtopic=1015856).

4PDA — стороннее сообщество. Этот проект не создаёт, не хранит и не проверяет прошивки из этой темы.

Используйте только прошивку, которая точно соответствует версии системы, плате, экрану, панели и загрузочной конфигурации вашей магнитолы. Неподходящая прошивка может помешать запуску устройства. Перед изменением прошивки сделайте полный резервный образ. Если точное совпадение не подтверждено, остановитесь.

Если Magisk уже работает, переустанавливать прошивку не нужно.

## Установка

1. Скачайте ZIP модуля из [последнего выпуска](https://github.com/cbkii/ts-docsui/releases/latest).
2. Откройте **Magisk**.
3. Откройте **Модули** и выберите **Установить из хранилища**.
4. Выберите скачанный ZIP-файл.
5. Перезагрузите магнитолу.

После перезагрузки откройте выбор файла из любого приложения. Должны появиться обычная внутренняя память, полная внутренняя память и корневая файловая система. USB-пункты видны только при подключённом накопителе.

## Если модуль не работает

1. Убедитесь, что устройство является TS18 с Android 10 и рабочим Magisk root.
2. После установки или обновления модуля перезагрузите устройство один раз.
3. Откройте модуль в Magisk и нажмите **Action**.
4. Найдите диагностический ZIP-файл по пути:

```text
/storage/emulated/0/Download/TS18-SAF-Diagnostics/
```

Приложите этот ZIP к новой задаче GitHub. Не устанавливайте другую прошивку только для проверки модуля.

## Безопасность

Модуль работает systemless через Magisk. Он не прошивает разделы boot, MCU, CAN, LCD, логотип или другие разделы прошивки.

Пункт **Root file system** имеет настоящий root-доступ. Не изменяйте и не удаляйте незнакомые файлы. Системные разделы только для чтения остаются только для чтения.
